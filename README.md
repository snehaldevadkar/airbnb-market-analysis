# 🏠 Airbnb Market Analysis

### Understanding NYC's Short-Term Rental Market Through Data

**Python · SQL · Excel · Power BI**

An end-to-end data analytics project exploring New York City's Airbnb listings to understand pricing patterns, room types, neighborhoods distribution, and availability. This project combines data preparation, exploratory analysis, SQL business queries, Excel summaries, and an interactive Power BI dashboard.

## 🎯 What I Wanted to Understand

This analysis explores questions that matter when evaluating a short-term rental market:

* Which neighborhoods have the most Airbnb listings?
* How do prices vary across neighborhoods groups?
* Which room types are most common?
* How does availability differ across the market?
* What patterns can be observed in listing reviews?
* How can these findings be presented clearly through a dashboard?

## 🔬 Analysis Workflow

The project follows a structured analytics process:

**01. Data Preparation — Python**

* Cleaned and prepared the Airbnb listing data.
* Checked data quality and prepared the dataset for analysis.
* Saved the cleaned dataset for reuse across tools.

**02. Exploratory Data Analysis — Python**

* Explored listing distribution and room types.
* Investigated pricing and neighborhood patterns.
* Examined availability and review-related characteristics.

**03. Business Analysis — SQL**

* Created SQL queries to answer market-related business questions.
* Used aggregations and comparisons to examine listings, prices, and neighborhood trends.

**04. Supporting Analysis — Excel**

* Organized cleaned data and summary information.
* Prepared supporting analysis for the project.

**05. Data Visualization — Power BI**

* Developed a two-page dashboard.
* Presented important market patterns through KPIs and visualizations.

## 💼 Why This Project Matters

A rental-market dataset becomes more useful when its information is organized into questions, comparisons, and visual findings.

This project demonstrates how different analytics tools can work together to:

* Explore market pricing and listing distribution.
* Compare neighborhoods and room types.
* Identify patterns that deserve further investigation.
* Present analysis in a format that supports easier interpretation.

The findings are descriptive and should not be interpreted as proof of causation or as guarantees of rental profitability.
